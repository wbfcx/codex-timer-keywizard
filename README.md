# Codex 定时继续工具

> 杂货铺编号：#003

一个基于按键精灵9制作的 Codex 定时继续工具。

用于设置指定时间或快捷延时，到点后自动发送 `F5`，激活设置为F5启动按键的Codex激活启动程序，让当前 Codex 任务继续执行。

可以源码中修改发送F5进行集成操作，推荐是激活另外的程序，本质上这是个定时装置，到时间后需要什么操作都可以切换

## 主要功能

- 设置指定执行时间
- 支持 30 分钟、1 小时、2 小时、3 小时、4 小时、5 小时快捷设置
- 支持 +5、+10、+15、+30 分钟等时间微调
- 默认设置为当前时间 +5 小时
- 使用 HTA 图形界面设置时间
- 到点后自动发送 `F5`

## 运行环境

- Windows
- 按键精灵9

## 使用方法

1. 将源码复制到按键精灵9
2. 运行脚本
3. 设置需要继续执行的时间
4. 保存并开始等待
5. 到达设定时间后，脚本自动发送 `F5`
